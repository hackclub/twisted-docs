# Starter Project Guides

Each guide below walks you through a specific board from schematic to shipped hardware. Pick the one closest to what you want to build, follow it, and select the matching guide when you create your project on Twisted — this is what lets you skip the journal requirement while you ship your first board.

| Guide | What you'll build |
| --- | --- |
| [Blinky Board (KiCad)](/Hardware/Starter%20Projects/blinky/) | A 555-timer LED chaser, designed in KiCad |
| [Blinky Board (EasyEDA)](/Hardware/Starter%20Projects/blinkyeda/) | The same LED chaser, designed in EasyEDA |
| [Squeak](/Hardware/Starter%20Projects/squeak/) | A custom mouse |
| [Split Keyboard](/Hardware/Starter%20Projects/split-keyboard/) | Your own split keyboard |
| [Midi Keyboard](/Hardware/Starter%20Projects/midi/) | A custom MIDI keyboard |
| [Custom Devboard](/Hardware/Starter%20Projects/devboard/) | An RP2040 development board |
| [Flight Controller](/Hardware/Starter%20Projects/flightcontroller/) | A flight controller board |
| [LoRa Puck](/Hardware/Starter%20Projects/lora/) | A basic RF board, and how RF boards work |
| [USB Hub](/Hardware/Starter%20Projects/USB%20Hub/) | A custom USB hub, from schematic through ordering |

New to PCB design? Start with a Blinky Board — it's the shortest path from zero to a shipped board.
