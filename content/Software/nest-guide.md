# Hosting on Nest

*Adapted from [Macondo's docs](https://macondo.hackclub.com/docs/nest-guide).*

**TL;DR:** [Nest](https://hackclub.app/) is Hack Club's free Linux VPS (virtual private server). You get your own machine to deploy websites, APIs, bots, databases, or anything else that runs on a server. To start, request an account at [hackclub.app](https://hackclub.app/).

<aside class="callout">

This full step-by-step guide is still being written — for now, lean on the official Nest docs and the friendly folks in **#nest** on the Hack Club Slack.

</aside>

## What you'll learn

- What Nest is, and what you can run on it
- Where to request your free server and get going today

## What you need

- A Hack Club Slack account, so you can request access and ask for help
- A project you want to host — a website, an API, a bot, a database, or anything else that runs on a server

## What Nest is

Nest is Hack Club's free Linux VPS. You get your own machine to deploy websites, APIs, bots, databases, or anything else that runs on a server — a great place to put your project online once it's ready to share.

## Getting started today

You don't have to wait for a deeper walkthrough to get up and running: head to [hackclub.app](https://hackclub.app/) to request your server, and ask in **#nest** on the [Hack Club Slack](https://slack.hackclub.com) if you get stuck.
